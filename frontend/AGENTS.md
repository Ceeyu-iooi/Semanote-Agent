# Vue 前端

先读根 AGENTS.md、docs/design/README.md、docs/web-contract.md、docs/annotation-contract.md。

- Vue 3＋JavaScript＋Bootstrap 5，Vite/npm；不用 TypeScript、其他 UI 框架或浏览器模拟存储代替真实后端。
- docs/design/tokens.css 是共享语义变量来源。Bootstrap 提供基础布局/控件，主题来自共享变量；业务与开发者页及各状态同一设计语言。不只用颜色表达状态/标签。
- 同一对象只有一个权威数据源；回包校验当前对象，失败保留输入/位置，筛选不静默改变批量范围。保存后重新读取，不用内存变化冒充持久化。
- 原文和模型结果按文本节点渲染，不执行 HTML；选区从 UTF-16 转码点，重复、emoji、换行、重叠/嵌套均可访问。旧标注仅在对应历史修订展示。
- 人工标注形成独立快照；自动候选显式保存，不覆盖人工版。分词变化使不兼容 POS 失效；统计/导出固定同一保存快照，草稿明确标识。
- 验证桌面/窄屏真实操作链，覆盖空内容、无搜索结果、网络失败、冲突与重新读取；保留键盘焦点、减少动效偏好。
- 构建后保留成品、锁文件与许可；npm ci 恢复开发依赖，确认产物可运行后裁剪。
