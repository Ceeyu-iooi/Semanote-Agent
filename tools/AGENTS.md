# 项目工具

先读根 AGENTS.md。工具有明确用途、输入、产物与恢复方法，不把一次检查变成无关长期门禁。

- 复用文档同步、初始化核查和本地 Archify；初始化与业务结论分开报告。
- 便携工具优先从官方发行渠道或可核实的镜像获取，按上游摘要或经上游原件核验的固定摘要校验，保留版本和许可。依赖镜像仅作用于本项目。
- 启停记录本项目进程身份，Windows 后台进程使用 Hidden；只停本次进程。真实配置、数据库、备份与回执放 profile。
- 清理核对绝对路径和本次归属，不触碰用户资料、外部日志或全局缓存。构建后验证裁剪产物并记录恢复命令。

- 维护工具使用 Node 原生 ESM。部署脚本默认使用国内 npm 镜像，`--source=official` 显式选择官方 npm 源。MySQL 使用已校验的官方运行清单。
- 更新 MySQL 运行清单时，先验证官方 ZIP 的发布摘要，再核对所需文件、压缩偏移和 SHA-256。用新安装验证初始化、启动、备份和恢复。
