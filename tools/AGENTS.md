# 项目工具

先读根 AGENTS.md。工具有明确用途、输入、产物与恢复方法，不把一次检查变成无关长期门禁。

- 复用文档同步、初始化核查和本地 Archify；初始化与业务结论分开报告。
- 工具仅从官方来源下载、校验发布摘要，保留版本/许可；不全局安装、不改其他项目。
- 启停记录本项目进程身份，Windows 后台进程使用 Hidden；只停本次进程。真实配置、数据库、备份与回执放 profile。
- 清理核对绝对路径和本次归属，不触碰用户资料、外部日志或全局缓存。构建后验证裁剪产物并记录恢复命令。

- 维护工具使用 Node 原生 ESM，不新增 Python。离线构建仅显式 --offline-from，复用核实本地 JAR 的依赖；在线失败不自动换镜像或绕过站点限制。
