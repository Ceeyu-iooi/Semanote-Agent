## 3. 实际验证

| 检查 | 实际结果及边界 |
|---|---|
| 普通模式与 `python -O` | 各 28 项测试通过；含独立/组合调用、Unicode/CRLF/组合字符、重复/重叠、POS 依赖、原文变化、失败层重试、非法返回、供应商配置/协议隔离、HTTP 错误脱敏和 CLI 不覆盖。替身测试不是 NLP 质量指标 |
| 真实 DeepSeek 四类能力 | 原创合成请求首轮：分词因空白词项失败，POS 报依赖失败且未调用；关键词 6 条、实体 7 条成功。显式重试只请求分词和 POS，最终得到分词 28 项、POS 28 项，原有关键词/实体及身份保持不变；没有自动重试 |
| 实体类别 | 实际合成输出出现 PERSON、LOCATION、ORGANIZATION、TIME、MONEY 五类；重复人名/地名位置分别保留。这是单个示例能力证据，不是各类质量达标证明 |
| 合法零结果 | 对原创纯标点/emoji 文本独立调用 NER，真实返回成功空列表；其他层为未执行；与失败时 null 结果不同 |
| 其他供应商 | 注入式 HTTP 协议测试通过：独立端点/模型/密钥/JSON 能力/扩展参数，不继承 DeepSeek 专有参数；未获其他供应商有效配置，未进行其远程测试 |
| Archify | 最终 HTML 的 validate、deliver、check、browser-check 全部通过；无诊断。另已人工查看 1440×900 浅色/深色截图，主流程、标签与箭头无可见裁切/遮挡；2048 截图仅自动检查 |
| 文档、原件与 Git 范围 | 文档同步、五份原件摘要与 CSV 基线审计通过；明确暂存白名单和实际密钥扫描通过。Archify 生成 HTML 保留上游字节，仅该文件通过 Git 属性关闭空白诊断；其他文件继续 `diff --check` |
