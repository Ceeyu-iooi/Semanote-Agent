# 工作台与开发者中心调整

- 模型用量按同一零线绘制双轴实线。日期范围变化后重播曲线，减少动效设置生效。
- Git 时间轴展示完整分支轨道和提交卡片，提交的文件列表与代码差异可滚动查看。变更记录左侧按版本跳转，窄屏改为顶部目录。
- 正文标注不使用深色轮廓。工作台使用蓝色指针，常用叠加层以标签常驻，语义、事件、关系、情感和意图从叠加选项中移除。两侧结果栏保留关系、事件、情感和意图，并移除原文分段、语义和分词入口。
- 固定展示标注详情，移除类别和排序选择。词云按频次从中心向外排列，悬停放大且不加边框或下划线。导出入口放在文本区顶部。
- 关系和事件使用随站点交付的 Archify 查看器。浏览器将当前修订的实体、关系记录和事件适配为节点和连线，点击可查看对应条目及原文证据。查看器使用本地页面及快照数据。
- 关键词、图表和正文的提示框采用各自适合的尺寸，正文类别前用彩点区分。
