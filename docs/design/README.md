# Semanote 设计规范

来源：[Apple DESIGN.md](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/apple) 与 [官方 preview](https://getdesign.md/design-md/apple/preview)。本地上游快照、许可和摘要见 apple/；这是 VoltAgent 对公开模式的独立分析，不是 Apple 官方规范或品牌授权。

当前项目规范 1.0，2026-10-28。查看 [可维护的 HTML 展示页](preview.html)。业务前端和开发者中心共同引用 [tokens.css](tokens.css)，不能各自复制颜色/间距形成第二套主题。

| 角色 | 规则与来源 |
|---|---|
| 品牌/交互 | Action Blue #0066cc；聚焦 #0071e3；暗面链接 #2997ff。保持单一蓝色强调 |
| 表面 | 白色 #ffffff、灰白 #f5f5f7、珍珠白 #fafafc、近黑 #272729；全宽区块用表面切换分层 |
| 文字 | #1d1d1f 主文字、#333333 次文字、#7a7a7a 辅助；暗面白色/#cccccc。正文 17px/400/1.47，强调 600 |
| 字体 | 使用系统已安装的 SF Pro Display/Text；Windows 回退 system-ui、Microsoft YaHei，不下载或再分发 Apple 字体 |
| 几何 | 操作胶囊、8px 工具、11px 珍珠控件、18px 卡片；细边框，无卡片/文字/按钮投影，无装饰渐变 |
| 间距 | 4/8/12/17/24/32/48/80px；最大内容宽 1440px，业务工作区按信息密度适配 |
| 动效 | 按下 scale(.95)，短透明度/背景过渡；尊重 prefers-reduced-motion；状态不改变控件几何 |
| 响应式 | 1068/833/640/419px 断点；窄屏单列、工具换行、原文断行，操作触区至少 44px |

## 本项目必要补充

上游没有表单错误、标注高亮和业务任务状态规范。补充沿用同一蓝/灰体系：错误以明确文字、边框和恢复动作表达；成功/失败/未执行不只靠颜色。标注以淡蓝背景、实线/虚线/下划线和完整类别文字区分，重叠在清单逐项展示，不增加第二个品牌强调色。

工作区使用白色阅读画布和细边框工具面，原文是视觉焦点；不把产品摄影或巨幅营销区块搬到标注操作区。开发者页可采用大字号标题与明暗区块，内部 preview 保持相同变量。Archify 的独立 Viewer 保留其上游交互/语义配色和许可，外围页面使用本规范；图的语义色不变成业务品牌色。

## 维护方法

1. 先核对已有角色和组件，新增需求优先复用；新规范在这里登记来源、用途与兼容影响。
2. 修改共享 tokens.css 和相应实际组件，在 preview.html 同步默认/聚焦/按下/禁用/加载/空/失败示例。
3. 验证业务页、开发者页和 preview 的代表性桌面/窄屏状态；不得只更新展示页而保留另一套业务值。
4. 上游原件保存在 apple/ 不改写；升级时记录新摘要与差异，不能静默覆盖已有设计含义。
