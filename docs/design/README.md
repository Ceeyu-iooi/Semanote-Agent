# Semanote 设计规范

来源：[Apple DESIGN.md](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/apple) 与 [官方 preview](https://getdesign.md/design-md/apple/preview)。本地上游快照、许可和摘要见 apple/；这是 VoltAgent 对公开模式的独立分析，不是 Apple 官方规范或品牌授权。

当前项目规范 1.3，2026-10-29。[项目 DESIGN.md](DESIGN.md) 保持上游 YAML 和 Markdown 章节格式；[HTML 展示页](preview.html) 沿用上游 01–12 展示顺序，追加用户要求的交互标注扩展。[六轮迭代](iterations.md) 记录实际变化。业务前端和开发者中心共同引用 [tokens.css](tokens.css)，不能各自形成第二套主题。

## 本项目必要补充

上游没有表单错误、标注高亮和业务任务状态规范。按本轮用户明确要求，分词使用边界线、关键词波浪线、词性色彩、实体类别底色，四层可叠加。语义色仅编码数据类别，操作和焦点仍保持唯一交互蓝；每种颜色伴随完整标签。错误以明确文字与恢复动作表达。

工作区使用白色阅读画布和细边框工具面，原文是视觉焦点；不把产品摄影或巨幅营销区块搬到标注操作区。开发者页可采用大字号标题与明暗区块，内部 preview 保持相同变量。Archify 的独立 Viewer 保留其上游交互/语义配色和许可，外围页面使用本规范；图的语义色不变成业务品牌色。

## 维护方法

1. 先核对已有角色和组件，新增需求优先复用；新规范在这里登记来源、用途与兼容影响。
2. 修改共享 tokens.css 和相应实际组件，在 preview.html 同步默认/聚焦/按下/禁用/加载/空/失败示例。
3. 验证业务页、开发者页和 preview 的代表性桌面/窄屏状态；不得只更新展示页而保留另一套业务值。
4. 上游原件保存在 apple/ 不改写；升级时记录新摘要与差异，不能静默覆盖已有设计含义。


## 0.1.1 交互扩展

来源为本轮用户的七幅界面示意，适用于工作台、图表与独立开发者页，兼容上游 01–12 章节及原有四层语义色。

- PointerTip：白底、细边框、11px 圆角，跟随指针右下 14/18px；测量真实尺寸，保留 8px 视口边距，滚动/调整视口/Escape 关闭。键盘焦点使用控件位置。无装饰投影。
- 主/开发者导航：顶部展示，窄屏横向滚动保留文字导航；正文区使用共享蓝色箭头指针，原文输入框仍可选择/输入文本。
- 原文分段和语义仅增加视觉换行；错误波浪线、情感色、关系/事件线条仅编码数据，操作仍是唯一 Action Blue。
- 当前文本图表必须显示数据来源版本，雷达轴为条目数量，不用作质量分数；关系角色及时间轴可返回原文证据。
- Git 横排左早右新，滑块在下，蓝色只填充已走过的较早区间；该填充是数据编码，不是装饰渐变。

## 沉浸工作区扩展

来源为用户中央原文、两侧抽取卡片草图及模型供应商截图，适用于本轮界面。保留上游 01–12 章节与原有颜色角色，追加第 15 章。

- 主界面与开发者中心使用顶部导航；设置保留侧边导航，供应商采用左侧列表、右侧详情。
- 桌面中央正文、左侧词项证据、右侧语义上下文，图表直接接在中央正文之后；≤833px 正文、图表、抽取卡片、编辑详情顺序。
- 结果卡片仅在已返回状态变化时，从靠近正文一侧偏移24px淡入，480ms轻微回弹；低动效模式无位移/淡入，不改变数据。
- Git语义色区分main/develop/release/feature，配合文字图例；图、卡片、时间游标联动。差异采用文件列表、旧/新行号与增删色，截断明确提示。
- 系统架构节点可下钻，面包屑返回；缩放过渡不阻断键盘访问。
