# 参考图驱动的全新界面与原型方案（待实施）

日期：2026-11-17。来源为用户提供的 Finexis 仪表盘截图及本项目的需求、接口和标注契约。截图只作为布局与视觉方向参考；本项目不使用其品牌、财务数据或人物图像。首页采用仪表盘，进入文本后打开标注工作台；前端继续使用 Vue、JavaScript 和 Bootstrap，并保留既有设计来源及许可证。

本文记录设计提炼，不代表用户验收已完成。现有 Apple 来源资料和许可证继续保留，实际设计以项目设计规范和已实现界面为准。

## 视觉提炼

- **整体结构**：浅灰紫页面背景包围圆角应用外壳；顶栏承载品牌、主要页面和全局操作，左侧窄栏提供快捷导航，主内容为白色圆角工作面。
- **信息层级**：页面标题与简短说明在前；最重要的摘要使用青绿色卡片，其他摘要、列表和图表使用白色或浅灰紫面板。卡片以细边框、留白和轻微表面差异区分，不靠密集阴影。
- **几何与文字**：大面板约 20–28px 圆角，常用控件约 10–14px，主要导航和操作可用胶囊形；正文使用适合中文的系统无衬线字体，标题深墨紫、标签与辅助信息使用可读的中性灰。
- **色彩起点**：外层 `#E8EAF2`、次级表面 `#F3F2F7`、卡片 `#FFFFFF`、主文字 `#211D38`、主操作 `#24203F`、青绿强调 `#50BDB5`。实际组件使用语义变量，并在实现时逐项检查文字、状态和焦点对比度；图中的浅色小字不直接照搬。
- **栅格**：桌面仪表盘按主要摘要、次级摘要、最近任务组织上排，统计和分布组织下排；面板按内容和可用宽度伸缩，不固定到截图像素。窄屏依次排列，表格仅在自身容器内横向滚动。
- **状态与动作**：深色用于主要操作和当前导航，青绿用于重点摘要或明确的次级强调；成功、失败、处理中均同时显示文字。图标按钮有可访问名称、可见焦点和足够触区。

## 页面与交互清单

| 页面或界面 | 主要内容 | 必须能演示的操作和状态 |
|---|---|---|
| 仪表盘 | 文本及已保存快照摘要、真实任务状态、最近文本、已保存标注统计 | 进入文本库、打开文本、新建或导入、查看任务和统计；空库、加载、失败；不得虚构增长率或质量分数 |
| 文本库 | 搜索、筛选、文本列表、来源摘要、当前修订与保存状态 | 新建、导入、选择、批量操作、归档与恢复；无结果、输入校验、导入失败和批量范围明确 |
| 新建与编辑 | 标题、正文及保存操作 | 输入、保存、取消；文本修改生成新修订，错误或冲突时保留输入 |
| 标注工作台 | 宽阔正文、图层开关、抽取结果与证据、版本状态 | 十一层切换，定位原文，自动标注与人工修改，明确保存候选或草稿；历史修订、冲突与失败恢复 |
| 自动标注 | 目标文本、图层、供应商和外发同意 | 选择、提交、队列/处理中、成功、部分失败、显式重试；区分合法空结果与失败 |
| 历史和导出 | 版本及快照身份、统计来源、JSON/TXT/Markdown | 切换历史、返回当前、从指定已保存快照导出；不可用时解释原因 |
| 任务 | 各任务及逐层状态、进度、失败原因 | 查看任务、按允许范围显式重试；进度只反映真实处理状态 |
| 统计 | 保存快照的实体、关键词、词性及各层分布 | 查看统计来源和范围，空状态；颜色之外提供标签或数值，不把覆盖率说成准确率 |
| 设置与日志 | 供应商配置及脱敏调用元数据 | 配置、保存、筛选日志、失败反馈；密钥不回显，未知用量不估算 |
| 开发者中心 | 设计规范、架构、真实 Git 信息与变更 | 浏览、下钻、返回；与产品使用同一视觉语言，示意图不冒充实际历史 |

工作台的业务规则仍由 [Web 契约](../web-contract.md) 与 [标注契约](../annotation-contract.md) 约束：Unicode 码点区间、修订与快照绑定、人工与自动结果隔离、统计和导出绑定同一快照。四项核心及新增七层均需保留。单人工作流和真实语料外发限制不因视觉改版改变。

## 原型与实现交接

原型需为 Axure RP 可编辑的 `.rp` 文件，覆盖上述页面、主要流转及空、处理中、失败、冲突状态；演示数据必须为原创合成内容。原型交互用于验证流程，不冒充真实数据库或模型结果。

代码迁移应先逐项对照现有能力和接口，再以原生 HTML、模块化 JavaScript 与 Bootstrap 实现；原型和代码分别进行桌面、窄屏、键盘及主流程检查。保存必须重新读取，自动结果不得覆盖人工快照；服务、数据库和智能体使用隔离测试数据验证，不外发真实语料。仅在新实现覆盖并核验旧能力后再清理失效 Vue 代码和依赖。
