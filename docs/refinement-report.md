# 交互标注工作台深化记录

日期：2026-10-28。需求来源及准确表述见 [本轮需求](refinement-requirements.md)；此前 Web/LAN 记录保留历史事实，本文件描述当前增量。未发布新版本，用户验收与 PR 合并另行进行。

## 当前实现

- 本地初始 train.csv 精确去重加入 1,607 份文本，保留 15,306 处来源。启动幂等，不覆盖原件、用户编辑或既有快照；常规导入支持 DOCX/TXT/MD/三列 CSV。
- 正文为中心的编辑器，字体/字号/行距、四层独立叠加、选区增删/改标签、候选审阅、历史和 JSON/TXT/Markdown 导出。人工与原文保存具有会话归属与并发恢复。
- Java/Python 传递真实逐层检查点，结果返回后播放词项呈现；不以扫描动画伪造模型百分比。新增交互统计和左下角设置，API Key 不下发浏览器。
- 独立 /developer 页面，维护六层 Archify、设计规范、实际 Git 提交/父关系/时间滑块/文件变化/代码差异和有分类的 Changelog。
- [设计规范](design/DESIGN.md) 与 [六轮记录](design/iterations.md) 保持 Apple 上游 YAML/Markdown 格式及 01–12 展示顺序，扩展 13 为用户要求的标注演示；上游原件/许可未改写。
- 新提交/PR/merge 使用 feat：或 fix：加中文概括；后续版本标签不加 v。GitHub 已启用合并后自动删除远程分支与 PR 标题作为 merge 默认标题。PR #1 的遗留本地/远程分支已核实安全删除，当前开发分支保留。
