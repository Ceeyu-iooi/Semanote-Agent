## 实现与边界

- Vue/JavaScript/Bootstrap 5：两侧独立单展开手风琴；只读频次柱图聚合相同词面/类别，保留出现位置、错误建议/原因；原文分段、关系、事件、语义不再占用只读详情标签。十一层人工编辑保留。
- 关系图同时显示人物和其他关系端点，包含原文信息摘要、方向连线与标签；鼠标拖动、方向键移动、缩放、恢复布局和悬停/聚焦灰化。曲线标签优先避让卡片与已有标签。相同词面聚合只是展示，不做身份消歧；复杂密集图仍可手动整理。
- 事件先列时间轴，选择后在中央展示事件原文介绍与六类要素。明确完整日期排序；局部时间、未知日期均保留，并明确无法确定绝对日期。没有生成原文之外的解释或人物履历。
- 统计突出保存文本、覆盖和实体，十一层详细数量移到展开区域；交互图表有选中状态。补齐缺失的共享浅蓝变量，使导航、选中卡片和图表反馈实际可见。
- 顶栏收紧；开发者入口集中到一行，子框架只从系统图卡片下钻。Git 从实际 refs 命名泳道，不明路径明确无现存分支引用；refs 为彩色 Bootstrap badge，固定左文件/右代码，窄屏堆叠。
- 页面、正文逐字、侧卡错峰、数字和设计预览滚动进入动效；文本完整存在，动效不改变内容和码点。保留减少动效偏好，设计 iframe 同步父页面偏好；设置稳定尺寸与内容滚动，修复窄屏导航被旧 flex 规则拉高。
- 智能体只发当前任务需要的提示规则，保留安全和逐字原文约束、联合推理、供应商隔离缓存与显式重试。后端保留文本块检查点和失败层，前端分别显示块处理与层校验，不用时间估算完成率。

本轮遍历前端组件/样式、共享呈现函数与后端 controller/service/repository/agent 入口和调用链；实际业务改动集中于任务进度适配。接口/持久化/Unicode 继续由既有隔离回归验证，没有为视觉改造重写无关后端。
