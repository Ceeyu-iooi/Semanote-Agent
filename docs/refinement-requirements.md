# 工作台深化需求与验收

来源：2026-10-28 用户本轮指令；沿用 Vue / JavaScript / Bootstrap、Spring Boot、MySQL 与独立 Python 智能体。

## 可执行需求

1. Git：后续版本标签不加 v；保留已发布历史标签。小提交、PR 与 merge 使用 `fix：中文说明` 或 `feat：中文说明`。PR/merge 综合本组提交。PR 合并后核实目标包含分支全部提交、无未提交修改及其他工作树占用，再删除临时本地/远程分支。集成分支仍为 develop（用户所称 dev）。
2. 开发者中心：独立 URL、独立导航和完整视口，离开业务布局；设计 preview、各层 Archify、实际 Git 提交图/时间滑块/提交详情/文件变更及有分类的 Changelog。
3. 设计：遵循上游 Apple DESIGN.md 的 YAML token 与 Markdown 章节格式，preview 沿用其导航、hero、色板、字体、按钮、交替明暗区、卡片、表单、间距、圆角、层次、响应式的展示顺序。至少 6 轮实际调整并记录依据/改动/检查。
4. 标注：正文编辑器占视觉中心，字体/字号/行距/选区工具与保存边界清楚；分词边界、关键词波浪线、词性色彩、实体底色可独立叠加。悬停/聚焦提示、人工增删/改标签、自动结果审阅保存、历史与导出形成真实闭环。
5. 过程：显示真实排队/逐层推理/校验状态；只在已返回条目上播放逐词呈现，不能把装饰动画当模型进度。支持减少动效。
6. 数据：本地 train.csv 初始可浏览/搜索/选用，精确去重后的 1,607 文本保留 15,306 来源位置；不覆盖原始文件或用户数据、不公开提交数据。兼容 TXT/MD/CSV/DOCX，导入失败原子回滚；DOCX 仅提取正文，不执行宏或加载外链。
7. 智能体：至少 9 轮代表性样本实测，校验四层成功/失败、分词完整覆盖、POS 一一对应、精确区间、关键词/实体原文一致和实际语义问题。记录模型调用与限制；结构完整不等于语义准确率。
8. 统计/设置：已保存快照的柱状图/环图与交互提示；左下角设置窗口配置界面/阅读/模型默认项，不向浏览器下发密钥。去掉无用常驻说明；窄屏以正文与主要操作优先。

## 本次数据授权与评估边界

用户明确回复“授权本次向 DeepSeek 发送代表性样本”。仅本次代表性样本、当前 DeepSeek；不扩大到其他服务、全库发送、公开或模型训练。语义准确率须有独立人工确认的金标准；现有 CSV 没有答案，不将模型自评或结构校验伪称准确率。原创确定性样例可检验预先指定的实体/词性和边界。
