# 标注工作台再设计记录

2026-11-15，依据用户本轮反馈执行。上一轮新增的靛色主题、共享变量和设计预览已回退至当前分支 HEAD 的视觉基线；启动兼容修复保留。

本轮实现：两侧手风琴改为连续面板；实体/词性/情感/意图/语义/错误按类别聚合，关系和事件按类型分组，同词面合并并展示出现数，仍可进入完整频次与原文证据；显示图层改为可折叠选择面板；进度压缩为单行状态、真实层回执百分比和一条进度条。移除工作台跨任务数量柱图、雷达图及空实体环图，保留实体类别构成和关系/事件证据。关系图按节点数紧凑排布；缺失事件角色隐藏；无确定日期时显示事件顺序。十一层使用统一线性 SVG 图标；模型日志增加当前页耗时交互图，点击联动详情，突出请求、复用、失败和已知缓存占比，未知用量不生成百分比。

缓存：同一供应商/文本缓存键在不同 bridge 进程间互斥，等待前一个任务发布通过校验的结果后再判断缺失图层，减少并发重复推理和写入覆盖。进程异常退出的锁通过存活检查回收；等待有上限，超时显式报错，不自动重发模型调用。供应商、端点、凭据、模型、规则及原文隔离保持原有规则。

验证：多次生产构建成功；既有智能体、前端与工具测试通过，并增加相同请求并发复用及独立进程锁测试。真实 Java/MySQL 隔离数据库中用原创合成文本检查保存后读取、实体分类、图层展开/切换/收起、关系卡片与证据详情、事件顺序、375px 布局及模型日志耗时图详情联动。中途发现固定大画布导致空白，已调整并重建。

边界：本轮没有远程模型调用，不宣称供应商缓存命中率已提升。尚未穷举每个控件、所有关系规模/重叠情况、浏览器与错误路径；这不是用户验收记录。设计预览按用户要求回退，未把本轮工作台改造成第二套展示主题。
