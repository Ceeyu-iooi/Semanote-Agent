# 0.1.1 候选交付与验证

日期：2026-10-28。对应 [本轮需求](0.1.1-requirements.md)。当前为 feature/0.1.1 开发候选，未创建 0.1.1 发布标签，不替代用户/课程验收。

## 当前实现

活动智能体为 Node.js 24 / JavaScript；Java/Spring Boot 后端保留。支持十一层标注、原文无损分段、人工修订、不可变保存快照及 JSON/TXT/MD 导出；旧四层数据继续可读。供应商可添加/编辑/选择，预置 DeepSeek 和本次指定百炼；凭据只保存在被忽略的本地配置，GET 仅给 hasApiKey。

每块最多 650 码点，多任务合并推理；原文、参数、端点、凭据摘要、提示内容与规则隔离成功层缓存。高亮采用边界扫描，避免逐片段重新扫描全部标注。真实块处理和图层检查点驱动进度，不把播放动画当推理进度。

正文后呈现当前展示版本的交互柱图、雷达图、实体环图、关系/事件卡片和明确日期时间轴。详情可按类别筛选和出现频次排序。主/开发者侧栏可收放；白底提示统一跟随指针并约束在视口内；Git 实际父关系横排、滑块在下、左侧较早区间填蓝。独立开发者页去掉 preview 顶栏，并增加模型调用日志。

## 八组迭代及最终回放

全部远程测试使用原创合成文本和本次配置的百炼 deepseek-v4.1-flash，没有把 train.csv 发送给百炼。每组保存实际模型候选，出现问题后修改通用转换/定位规则，再进行针对性远程检查或原始候选离线回放。没有把离线回放计为新的远程请求，也没有把结构覆盖称作准确率。

| 轮次 | 目标与观察 | 修正及最终检查 |
|---|---|---|
| 1 | 实体、关系和事件；相同证据可有不同主客体 | 关系去重使用完整关联身份；十一层回放通过 |
| 2 | 六句情感/意图及上下文角色 | 角色保留独立原文来源；歧义须明确出现序号；回放通过 |
| 3 | 列举、语义分段、词性标签 | 不接受 TIME 充当 UD 词性；按源顺序定位，关系证据扩展到原句；回放通过 |
| 4 | 三类错误建议与事件角色 | 建议与原文分离；句子上下文消除“我/我们”等位置混淆；回放通过 |
| 5 | emoji、CRLF、重复词及模型新增标点 | 仅丢弃模型新增标点，原文字符仍完整顺序匹配；最终另一次真实十一层调用与缓存复用均通过 |
| 6 | 1,070 码点长文、两块、重复句子 | 源顺序定位替代模型重复序号；跨块角色来源与 POS 依赖核验；最终两份真实候选回放通过 |
| 7 | 空实体层、混合情绪、列举语义 | 成功零条目与失败区分；十一层回放通过 |
| 8 | 日期、时间、地点、原因与结果 | 原文证据和事件角色分离定位，明确日期进入时间轴；十一层回放通过 |

最终八组回放均为 11/11 层通过结构、跨度、依赖与原文覆盖校验。离线回放处理约 4–26 ms；此数不包含模型推理、Java 子进程启动和 HTTP 往返。完整语义质量仍需要独立金标准与用户验收；D10 没有被自检代替。

## 同文成本与效率对照

同一原创短文、同一供应商/模型、同四项核心任务，进行一次受控对照。逐项执行与合并执行均经过同样原文校验，不推算货币费用。

| 方式 | 实际远程请求 | 输入 token | 输出 token | 合计 token | 本地计时 |
|---|---:|---:|---:|---:|---:|
| 逐项执行 | 4 | 2,836 | 473 | 3,309 | 19,855 ms |
| 合并执行 | 1 | 715 | 275 | 990 | 2,134 ms |
| 相同任务本地缓存复用 | 0 | 0 | 0 | 0 | 12 ms |

该次样例请求数减少 75%，总 token 减少约 70.1%。供应商为合并请求报告缓存输入 512 tokens；不承诺所有请求的服务端缓存命中率。网络时延波动明显，单次计时不能作为总体性能保证或货币成本比例。

独立评估的请求/回放、受控对照和网页任务分别留回执；不把同一工作空间中其他人工测试混入上述对照。完整本地记录在 profile/verification/0.1.1，日志模块记录实际 usage，缓存缺失值是未知。

## 运行与交互验证

- JavaScript 智能体 18 项：十一层、重复/重叠/emoji、长文分块、缓存隔离与零远程复用、依赖和显式恢复、数据库 JSON 键顺序、严格 JSON、源标点与句子定位。
- 前端 6 项：候选归属、历史数据隔离、叠加扫描、重叠选区及局域网 UUID。
- 历史 Python 兼容 35 项本地测试通过；不作为新增 JavaScript 能力的证据。
- Java 12 项：导入、来源边界、DOCX、供应商配置/密钥遮蔽/地址变更保护。
- 隔离 MySQL 20 项：真实 HTTP/JDBC/JavaScript 十一层人工保存、原文修订、并发冲突、原子导入/容量、Host/Origin、拒绝未配置供应商、无隐式推理的中断恢复、SQL 备份与空库还原；本组远程调用为 0，临时库已清除。
- 真实浏览器：自动候选保存并回读、十一层人工确认保存、分类/频次筛选、三种逐篇图表、事件选择和证据、设置增添草稿取消/重新读取/保存、日志来源筛选/分页/无结果、两页侧栏收放、Git 左早右新与左侧填充、preview 顶栏移除及新增规范章节。
- 1440×900 与 480×844：正文和导航可用，页面无横向溢出，设置窗口在视口内；图与表各自横向滚动。白底提示的实际背景/边界已检查。真实手机长按、拖动手柄尚未实机验证。

独立前端源码复查定位并关闭了：重叠片段位置错位、历史原文误导出当前快照、扩展文本导出字段丢失、切历史未退出原文编辑、移除条目导致编辑对象漂移、双编辑态。最终刷新另发现并修正筛选监听器初始化顺序错误；模型设置使用独立草稿，关闭不污染可调用供应商列表。
