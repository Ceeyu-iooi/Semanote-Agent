# 文档与开发者资料

先读根 AGENTS.md。本目录保存可公开规范与原创示例说明，原件仅在 profile。

- 课程要求以 requirements.md 页码为证据；用户新增要求单独登记，不默改原件含义。模板日期、成员与工作量不是事实。
- workflow.json 是五步状态和提示词的唯一编辑源；修改后同步并 --check。历史报告保留当时事实，新增当前状态说明与链接。
- decisions.md 记录确认来源、日期、影响与未决边界；acceptance.md 只记录真实用户准入/验收。当前选型与历史 pending 明确区分。
- design/README.md 是设计入口；维护离线 preview.html、共享 tokens.css、来源和许可。新规范说明适用范围及与已有组件的兼容关系，不随意更换整体风格。
- 开发者中心展示设计 preview、系统/智能体/前端/后端/数据库 Archify 图、Changelog 和 GitFlow。维护图源与最终 HTML，明确已实现和规划边界，不把示意当测量。
- 不生成虚构截图、指标、报告工作量或文献；课程正式报告和敏感资料不公开。
