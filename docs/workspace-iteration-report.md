# 工作面与统计界面迭代记录

- 工作面改为独立滚动；文本库压缩选择列并恢复打开箭头；任务完成状态使用亮色标记。
- 开发者规范预览沿用原预览页结构，去掉独立组件展示入口；系统总览不再显示额外导航条。
- 模型日志新增北京时间按日汇总；保留未知用量，命中率按缓存输入 Token 加权。选择近 7 天、近 30 天或全部可改变图表范围。
- 详情频次改用可选圆形分布，保留原文证据定位；覆盖率使用圆环，关键词使用紧凑词云。详情切换与两侧手风琴展开状态分离。
- 计数动画参考 Lingxi 的逐帧缓动思路，独立实现；该参考项目使用 CC BY-NC 4.0，未复制源码。来源：https://github.com/Ceeyu-iooi/Lingxi-Workspace/blob/main/frontend/app/count-motion.ts
- 本地验证：前端生产构建成功；Java 全套 14 项测试、Node 51 项测试和工作流同步检查通过。浏览器检查了工作面滚动、日期筛选、暗色设置和设计规范入口。
- 后续复核：在窄屏检查了首页、模型设置、标注正文和开发者规范；修复暗色选中状态、返回按钮及规范页次要按钮的对比度。开发者页面也使用固定外壳与内部滚动。逐篇实体分布改为环图，详情按类别使用环图、按词项使用气泡图，关系与事件保留图谱和时间轴。
- 智能体兼容实际请求等价的地址末尾斜杠，复用历史缓存；不同凭据与端点仍隔离，词性缓存必须匹配保留的分词。自动测试覆盖旧缓存、并发和分词不匹配场景；尚无真实使用数据证明整体命中率提升。
- 本地只检查了代表性视口和状态，并未逐一穷举所有设备与业务数据；实际验收仍需用户检查。README 首页截图仍为上一轮原创合成示例，尚未替换为本轮界面。
- 追加调整：文本与归档表格固定列宽和滚动条空间；每日图表补齐无记录日期并使用竖向指示线；原文按标注区间而非逐字拆分，类别详情默认显示分布与证据，关键词使用词云。关系图按无序端点对聚合，保留每条原始关系和可确认的共同事件；同名仅按词面聚合，不推断身份或人物特征。移除了独立实体概览，关系图采用缩放按钮和可扩展画布。
- 未执行拖拽性能录制，不能据此声称已达到特定帧率；本地缓存仍沿用上一轮已测试的兼容复用与隔离策略，未测量新增实际命中率。
- 恢复开发依赖：`npm ci --prefix frontend`；构建后使用 `npm prune --omit=dev --prefix frontend` 恢复运行依赖集合。
