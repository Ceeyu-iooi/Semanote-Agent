# 全项交互补验与实施记录

2026-11-01开始、2026-11-02收尾。用户反馈上一轮未完成，并明确要求全部重新复核。本次继续修改 feature/immersive-workspace，按 vibehub 将需求改成可观察行为，见 [需求及细化](interaction-requirements.md)。以下为本地实施和检查记录，仍待用户验收，不代表发布或课程验收。

## 本次具体改动

Vue、JavaScript、Bootstrap 5 保持原选型。Bootstrap 的表单、导航、手风琴、按钮组、徽标、栅格和进度结构实际参与页面；主题仍来自共享设计变量，交互由 Vue 单一状态控制。

正文默认显示关键词、实体及无损分段，避免五层同时强调。两侧各自单展开，收起内容设为 inert，展开区内部滚动；侧卡显示真实关系端点和事件时间。原文编辑、人工草稿、候选及已保存结果明确分开；取消恢复，人工编辑仍有十一层。

只读详情彻底排除分段、关系、事件、语义；其余七层用柱图显示词项或类别、次数、占比。词性等默认按类别聚合，点击条目先展开全部出现证据，再选具体位置返回正文，保留错误建议。相同位置去重，区间仍为 Unicode 码点。

人物图默认只显示人名卡片，可切换全部实体；卡片显示直接关系摘要，点击展开有据的原文资料，可拖动/键盘移动/缩放/恢复。悬停或聚焦时其他卡片覆盖灰色蒙层。事件用时间轴选取，再展示原文、六类角色及相邻原文介绍；不虚构人物履历、时间、原因或结果。修复重复点击同层图谱入口仍停留在旧页签的问题，入口也同步具体关系/事件选择。

开发者单顶栏保持六个入口，四个子框架通过系统图卡片进入。Git 使用真实父关系，main/develop 固定不同轨道，侧面显示实际名称；空引用不生成名称，历史不可核实名称明确标注未知。彩色 refs 和固定左文件/右代码继续使用真实仓库数据。

统计建立已保存文本主指标、实体/总条目次指标、实体/关键词与词性/覆盖图的层级；数字使用稳定卷轴。层覆盖明确以已保存文本为分母，保存总覆盖仍以全部文本为分母，均不表示质量。页面切换、卡片错峰、设计规范滚动进入及减少动效统一处理。设置固定尺寸与内部滚动。

任务进度保留真实阶段、块和逐层状态，增加真实请求/缓存计数、已知 token 与已耗时；失败单独表示，终态停止无用轮询。模型提示精简重复规则，可选共享原文证据字典，本地还原后继续严格校验；未改变 Web/导出契约。静态资源增加重新校验，解决构建后导航到开发者页仍使用旧入口缓存的问题。[Spring Boot 3.5 配置依据](https://docs.spring.io/spring-boot/3.5/appendix/application-properties/)
