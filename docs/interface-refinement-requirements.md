# 界面与统计调整需求

来源：2026-11-17 用户补充的十张截图和文字说明。沿用 Vue、JavaScript、Bootstrap 与既有业务契约。

1. 扩展首页内容宽度，图表在悬停和键盘聚焦时显示类别与真实数值。浅色和深色以并列选项呈现，保留扩散切换与减少动效支持。
2. 品牌、主导航、主题和工具各自呈现，顶部不额外铺设背景层；主界面和开发者中心共享外壳颜色，架构图随主题切换。
3. 模型日志显示实际输入、输出、总 Token 和缓存信息；按可选的近期调用范围展示用量和缓存命中率，明确未知值和统计口径。
4. 设计规范及组件展示参照既有预览的章节、尺度和层次，使用当前项目配色；内页不重复设置导航。
5. 任务分类使用连续切换的分段控件；任务和文本库用紧凑表格显示名称、时间、状态及必要操作，文本库不展示正文预览。
6. 统计概览不使用横向条形图；保持数值、类别及数据范围可查。
7. 修复深色主题中原文高亮、标签、操作、弹窗和架构图的可读性；检查桌面和窄屏。
8. 核对前后端相关数据来源及界面路径，更新 README；供应商标识只使用可核实来源和适用条件的素材。

用户确认：近期曲线按标注任务汇总同一任务的调用。筛选应用于调用记录后再汇总；无任务 ID 的独立调用不进入任务曲线。
