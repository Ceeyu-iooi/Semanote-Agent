# 界面与统计调整记录

本轮按用户确认，以标注任务为单位汇总模型调用。后端在筛选后、表格分页前按任务分组；前端提供最近 10、20、50 个任务的 Token 与供应商缓存命中率曲线，并对缺失用量断线。本地复用单独显示，不当作供应商缓存。

完成了首页宽度与图表提示、两选项主题切换、独立顶部控件、架构图主题同步、文本库与任务表格、统计覆盖卡片和词性柱图、标注高亮的深色对比度修复，以及设计规范和组件展示的重新组织。详细需求见 [需求记录](interface-refinement-requirements.md)。

验证：前端构建和现有 16 项前端测试通过；后端任务聚合单元测试通过。隔离演示验证了曲线数值与提示、架构图主题切换；实际本地工作区验证了文本库、深色标注正文及设置窗口。后端在确认没有活动任务后通过项目工具重启，实际日志接口返回任务汇总。未执行真实模型远程调用。设计预览和组件展示已在桌面检查，未覆盖所有页面和窄屏状态。
