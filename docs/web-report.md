- 文本新建/编辑/精确原文展示、UTF-8 TXT/三列 CSV 原子导入、来源行列与重复追踪、全文搜索、归档和恢复。
- 四层自动标注任务、持久队列、幂等请求、逐层成功/失败、候选审阅与显式失败层重试。POS 依赖分词，不自动重发或切换供应商。
- 人工划选实体/关键词、类别修订与移除、分词/POS 编辑；原文作为文本节点显示，选区转码点，重复/重叠区间可逐项访问。
- 不可变原文修订和标注快照、人工/自动来源及基线追踪；原文改变后当前标注清空，旧结果绑定历史。乐观冲突保留草稿并支持载入最新版本继续核对；保存回包、历史选择和弹窗重载按对象及会话隔离。
- 同一保存快照驱动统计与 JSON 1.0.0 导出；区分缺层、失败与成功零条目，不把候选或草稿算入正式统计。
- 单人本地工作流；多用户身份/角色/任务分配只保留扩展设计，未实现登录或公网部署。
