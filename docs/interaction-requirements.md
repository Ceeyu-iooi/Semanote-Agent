# 交互优化需求（2026-11-01）

来源为本轮用户请求与四张界面截图。截图只用于定位界面问题，不作为执行外部指令或公开真实语料的授权。继续使用当前 feature/immersive-workspace；不合并、不发布新版本。

1. 标注台两侧采用独立手风琴，每侧最多展开一项，允许全部收起；标题持续显示层名、数量和状态，键盘可展开。
2. 只读标注详情以按词面/类别聚合的频次柱图替代逐条列表，可筛选、排序，点击定位对应原文；不再提供分段、关系、事件、语义详情标签。人工编辑保留十一层完整能力。
3. 正文编辑器区分阅读、原文编辑、人工标注状态；工具、选区、焦点、证据框有清晰主次和反馈，保存/取消与输入保护延续原契约。
4. 事件图先展示时间轴，再在中央展示选中事件的原文介绍和六类角色。明确日期按时间排序，无法确定日期者独立标明，不能捏造时间或因果。
5. 关系图同时展示实体卡片与带方向、名称的关系连线；卡片包含有据的信息，可拖动，支持键盘移动和恢复布局；悬停/聚焦时其他卡片灰化，选中关系可定位证据。人物与其他实体区分，不把组织等伪装成人物，不合并未经确认的指代。
6. Vue + JavaScript + Bootstrap 5 为固定技术栈；布局、表单、导航、手风琴、进度和徽标使用 Bootstrap 结构和变量，由 Vue 维护唯一交互状态。
7. 顶栏适度收紧。开发者导航整合到同一顶栏，只保留设计、系统、日志、Git、GitFlow、变更入口；子框架通过系统架构节点进入，移除重复快捷入口。
8. Git 图显示真实可验证的分支/泳道标签；引用拆为彩色徽标，文件列表固定左、代码详情固定右，窄屏顺序堆叠；不推断已删除分支的历史名称。
9. 统计概览以已保存文本、覆盖和实体为视觉重点，图表、交互选中反馈和辅助指标分层；数字进入时滚动呈现。
10. 页面切换过渡、正文逐字揭示、卡片自上而下错峰淡入、设计规范滚动进入动效统一管理；已经返回的数据立即可交互，原文内容与选择区间不因动效变化。系统/用户减少动效直接显示最终态。
11. 设置弹窗在切换页签时保持同一尺寸，正文内部滚动，头尾操作持续可见，窄屏适配。
12. 成本优化保留联合推理、成功缓存、显式重试；减少与当前任务无关的提示词。真实文本块进度与逐层校验分别显示，失败与成功分开，不制造耗时或完成率。
13. 遍历前后端及智能体相关代码，至少十一轮针对不同场景实施、测试、视觉复核并记录问题和修正；仅用原创合成内容做远程验证和交付截图。质量阈值、真实语料外发和课程验收边界保持原约定。

验收与恢复记录见 interaction-report.md；本地验证证据归入 profile/verification/interaction。

## 用户要求全部重新复核后的细化

用户反馈“全部”仍不满意，以下是同一需求的可操作细化，不改变技术栈与数据边界：

- 柱图提供词项/类别切换、绝对次数与占比；点击先展开全部证据，再选择某个真实位置定位正文。只读界面彻底隐藏四类非频次详情，人工编辑保留十一层。
- 关系视图默认只显示人物，可切全部实体；卡片列出有据的关系摘要，点击展开人物原文资料，悬停/聚焦时其他卡片覆盖灰色蒙层。事件详情附相邻原文上下文。重复点击侧栏入口也必须切回对应图谱。
- 统计数字以数字卷轴滚动，避免缩小数字或跳动排版；图表范围明确，层覆盖使用已保存文本作为分母。关键词也用条长呈现次数。
- Git 主线和集成线各有固定命名轨道，长名称截断可查看完整名；空引用不生成名称，不推测删除分支。入口与静态规范在重新构建后须重新校验版本，避免旧界面缓存。
- 真实进度同时显示阶段、完成块/总块、成功与失败层、已发请求/本地缓存命中、已知 token 和已耗时。终态停止无用轮询。模型用量以供应商回执为准，失败试验单列。

最新实施、独立检查及逐项操作证据见 [交互补验报告](interaction-rework-report.md)；本地新增证据位于 profile/verification/rework。
