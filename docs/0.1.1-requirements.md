# 0.1.1 实施需求

来源：2026-10-28 用户本轮指令。目标版本 0.1.1，开发分支 feature/0.1.1；检查完成前不创建发布标签。

1. **模型与运行**：Java/Spring Boot 后端保持不变，活动智能体改为 Node.js/JavaScript，通过标准输入输出调用。保留旧 Python 交付的历史兼容说明。设置支持添加、编辑、选择 OpenAI 兼容供应商；预置原 DeepSeek 和用户指定百炼，密钥只在本地受忽略配置中保存，读取接口仅返回是否配置。之后本轮远程测试使用百炼 deepseek-v4.1-flash、原创合成文本；既有 DeepSeek 真实样本授权不扩展到百炼。
2. **标注**：保留四项核心，新增原文分段、关系、事件、句子情感、意图、语义、语法/用词/错别字。文字、顺序和原始换行不可重写；语义分段仅作为显示层插入视觉换行。所有证据定位到原文码点；建议改写与原文分开。未出现的事件角色保持缺省，不补造事实。
3. **效率**：合并同一文本的多项推理，固定提示前缀、压缩模型候选格式，长文按原文边界分块；以供应商/端点/模型/参数/规则/文本摘要隔离本地结果缓存，复用经校验成功结果。记录真实请求次数、耗时、输入/输出/供应商缓存 token；价格未知时不编造金额。失败不隐式重发。
4. **工作台**：详情按标签筛选、出现次数排序；逐篇正文后展示本篇当前结果统计，明确候选/草稿/已保存来源。提供交互柱图、环图、雷达图；关系/事件用可选择卡片图和有原文时间依据的时间轴。支持人工修订与保存/导出扩展层。
5. **交互**：侧栏收放；删除连接状态和开发者 preview 顶栏；白底悬浮提示跟随鼠标右下方，碰撞视口时调整；文本画布使用用户示意的蓝色指针，编辑输入仍保持文本选择能力。Git 真实父关系横排、提交可选、下方时间滑块左早右新，蓝色填充较早侧。
6. **调用日志**：持久化脱敏调用记录，支持供应商/模型/状态/缓存筛选、排序、分页及交互统计；不记录正文、密钥、供应商原始错误。
7. **文档与设计**：使用 beautify-github-readme 重构整体 README；Apple 共享设计规范新增兼容的提示/图表/侧栏规则，维护 preview、Archify、Changelog 和职责规范。
8. **验证**：至少八轮，每轮记录目标、真实结果、问题与改进，覆盖契约、能力、缓存成本、长文、失败恢复、持久化、桌面/窄屏及交互；全量检查受影响路径。模型判断与结构覆盖区别呈现，质量阈值仍受 D10 约束。
