新增 · 标注工作台

Vue / JavaScript / Bootstrap 前端与 Spring Boot / MySQL 后端，支持原文管理、搜索、修订、归档、批量自动任务、人工校对和不可变快照。

以正文为中心的编辑器、字体/字号/行距工具、四层独立叠加、选区标注、词项提示、真实逐层进度与结果呈现动画。

已保存结果的交互环形图、柱状图及频次提示；JSON / TXT / Markdown 快照导出；左下角界面与模型设置。

DOCX / TXT / MD / 三列 CSV 导入；本地初始语料精确去重并保留原始行列来源。

改进 · 智能体

独立 Python 智能体保留四类任务、供应商隔离、严格区间/依赖校验及显式失败层恢复。

修正小数标点分词失败、轻微原文字符改写与重复实体序号问题；通过源文本定位实体，补齐明确日期和货币格式。
