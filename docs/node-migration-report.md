# Node.js 迁移验证

2026-11-19，面向 develop。Windows 本地运行使用 Node.js 24、Vue、Bootstrap 和既有 MySQL 8.4 表。原文、修订、任务、快照和导入来源继续使用原存储结构。旧项目副本占用 8080，本项目发布端口使用 8090，开发使用 5173 和 8081。

| 检查 | 结果 |
|---|---|
| 自动化测试 | 63 项通过，涵盖智能体、前端表现层、工具与人民币峰谷价格边界 |
| 隔离 MySQL / HTTP | 26 项通过，含 Unicode、版本冲突、十一层快照、断点任务恢复、SQL 备份还原、限量导入与 15,306 份合成文本导入 |
| Edge 浏览器 | 选定导入数量并显示实际进度，拖动关系证据，查看曲线悬停与键盘选点、缓存比例和金额。取消退出保持服务，确认后 HTTP 和 MySQL 停止 |
| 运行模式 | 5173 可代理 8081 的读写。发布入口 8090 可服务已构建页面，重复启动可复用现有进程 |
| 模型调用 | 仅用原创合成文本测试 DeepSeek。首次词性标注成功，第二次从本地复用，联网调用为 0 次 |

历史失败回执显示词性依赖分词，分词曾因输出截断、标点校验或词项缺失而失败。本次按输出预算限制块大小，保留完整词项，接受可对齐的固定分词词性重试回包，并保留不通过原文校验的失败状态。运行业务时直接调用智能体模块，批量写入使用参数化多行语句，调用日志增量读取完成记录。

缓存分为供应商前缀 Token 和本地结果复用。旧远程记录的命中状态根据已记录的缓存 Token 修正。供应商缓存取决于实际回包。等效 API 价值按核验时的官方人民币价表和请求开始时间计算，其他供应商使用 Flash 参考价。节假日表覆盖 2026 年和 2027 年。
