# 仪表盘改造进度

2026-11-17。用户要求停止使用 Apple 来源设计规范，首页参考所给仪表盘，其他页面保持原业务布局并融入新视觉。此前明确要求最终前端采用 HTML、JavaScript、Bootstrap；本轮实现仍基于现有 Vue，迁移尚未完成。

已完成：新增首页，使用 `/documents`、`/jobs` 和 `/statistics` 的实际结果展示未归档文本、已保存快照、任务状态、图层数量、实体数量及最近文本。首页按钮复用现有导航、新建弹窗和文档打开流程。时间序列接口不存在，因此不生成参考图的趋势数据。共享设计变量改为深紫、青绿、浅灰紫及白色，业务外壳、按钮和首页采用新样式。原有工作台及业务操作代码保留。

验证：前端构建成功；现有 Node 测试 53 项通过。`node tools/verify-web.mjs` 使用原创合成数据和隔离数据库连续运行 5 次，覆盖 Java、JDBC、MySQL 与 JavaScript 校验器、十一层人工快照、导入、导出、并发冲突及备份恢复；未调用远程模型。这 5 次是同一接口回归的重复，不等于五轮完整浏览器端到端测试。使用本地合成响应查看桌面及 375px 首页，检查新建弹窗打开/取消及文本库导航；没有验证真实后端上的新首页操作。

未完成：移除 Vue 并保留全部功能、逐页面替换旧视觉和 Apple 来源预览、真实浏览器与隔离后端完整联调、自动标注模型调用、网络失败/冲突/窄屏等完整场景、至少五轮含前端的联调和用户验收。本轮不能声称全站一致或完整交付。

恢复开发依赖：`npm ci --prefix frontend`；前端产物保留在 `frontend/dist`。真实数据、密钥和原有工作树改动均未清理。
