# JavaScript 智能体

先读根 AGENTS.md 与 docs/annotation-contract.md。本目录是 0.1.1 起活动智能体，Node.js 24 原生 ESM，无运行时第三方依赖；Java 仍是 Web 后端。

- 只通过 JSON/NDJSON 管道收发，不执行原文或模型输出；凭据来自本地配置，不写命令行或回执。
- 所有位置为 Unicode 码点，原文无损；模型候选经本地转换和依赖校验后才可保存。缺失信息不虚构。
- 合并推理、分块和缓存均需保留出处；缓存隔离供应商/端点/凭据摘要/模型/规则/参数/任务/文本。缓存文件只放 profile，不公开。
- 日志只记元数据和实际 usage，缓存缺失值是未知；失败不自动重试或切换供应商。
- 本轮百炼仅发送原创合成文本。旧 DeepSeek 真实样本授权不扩展；无人工标准不报告真实语料准确率。
