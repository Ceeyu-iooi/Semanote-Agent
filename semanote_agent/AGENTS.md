# 独立智能体

先读根 AGENTS.md、docs/annotation-contract.md、docs/agent-usage.md。

- 保持 Python 3.12 标准库模块/CLI 独立，不耦合数据库或 HTTP 框架。
- 契约 1.0.0、码点区间、标签、依赖、原文摘要、逐层状态须运行时校验，不用 assert 代替。
- 模型输出是不可信数据，只解析和校验；供应商隔离、脱敏错误，不自动重试/切换。显式恢复保留成功层与旧尝试。
- 原创合成验证不等同语义质量评估；真实语料外发需 D09 授权。
- 本次 D09 仅授权当前 DeepSeek 的 train.csv 代表性样本测试，不能推导全库发送或其他服务授权。CSV 没有答案，不把完整覆盖/结构校验称为准确率。
- 推理候选以原文为准：确定性标点拆分、受限的同长度原文投影、实体精确出现定位、明确格式日期/金额补全均需保留规则与回归；模糊或无效候选不能猜测成成功。
